# YUMENO v0.2.0

YUMENO v0.2.0 将项目收束为本地优先的角色化 Agent/RAG 工作台：知识库与记忆是默认能力，Skill、MCP、Tool 作为角色级可授权扩展；QQ、B站、语音和 Live2D 继续作为独立接入层复用同一角色运行时。

## 主要变化

- 角色 Agent/RAG：知识库优先检索、上下文预算、短期/长期记忆、能力策略、执行观测和离线评测。
- 能力扩展：标准 Skill、MCP、Tool 注册与角色授权，支持在线扩展目录和 Skill 安装。
- 可视管理：Vue 角色能力图统一管理设定、知识库、记忆、声音、Live2D 与扩展能力。
- 多渠道接入：B 站弹幕队列与 NapCat/OneBot 11 私聊/群聊回复，支持文字、分片语音和窗口级记忆。
- 本地语音：统一采用 GPT-SoVITS，支持音色训练、角色绑定、试听和流式合成。
- 结构化知识：受权限保护的只读 SQL 查询和复杂表格导入。

## 重要修复

- 系统设置页 TTS 状态现在正确反映 GPT-SoVITS 的安装、就绪和运行状态，不再持续显示灰色。
- 修复快速连续消息、工具触发循环、搜索过程外泄、Live2D 页面切换和 NapCat 配置回滚问题。
- 修复 MCP 2.0 工具 schema 与结构化结果字段兼容，stdio 服务可保持会话并正常调用。

## 升级说明

- 本版本移除旧 Lunar/Qwen3-TTS 运行时，现有语音工作流统一迁移到 GPT-SoVITS。
- 本地角色数据、Milvus 数据、模型目录与运行时不包含在源码包内，升级代码不会主动删除这些本地数据。
- 正式安装包不携带本机 Live2D 模型或测试音频，避免将个人模型与未授权素材发布到公开 Release。
- 需要 Python 3.11；Milvus 仍由 Docker Desktop 运行。
