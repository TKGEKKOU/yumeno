# YUMENO Vue 渐进迁移与视觉语言

## 迁移结论

Vue 的价值主要在于管理异步状态、页面生命周期、轮询、复杂表单和动态列表，而不是单纯改变外观。YUMENO 保留现有静态应用壳，使用页面级 Vue 挂载点逐步迁移。

| 顺序 | 页面 | Vue 收益 | 决策 |
| --- | --- | --- | --- |
| 第一批 | 能力扩展 | Skill、Tool、MCP、在线目录和安全状态高度动态 | 已迁移 |
| 第一批 | RAG 评测 | 运行进度、指标、逐条结果和轮询生命周期明确 | 已迁移 |
| 第二批 | 创建角色 | 上传、分析、确认是清晰状态机 | 后续迁移 |
| 第二批 | 系统设置 | 表单和资源状态复杂，但敏感配置较多 | 按模块迁移 |
| 第三批 | 声音 | 长任务、上传、试听和轮询适合组件化 | 待统一任务模型后迁移 |
| 最后 | 对话 | 流式回复、TTS、ASR、Live2D 与打断链路风险最高 | 稳定优先 |
| 冻结 | QQ 接入、B站直播 | 当前功能稳定且存在 WebSocket、轮询和共享 Live2D | 不迁移业务逻辑 |

## 视觉参考提炼

参考明日方舟官网及世界观页面时，仅吸收可用于桌面工作台的视觉语言，不复制角色图像、品牌标识或版权素材。

- 黑、白、灰构成信息底盘，青色只作为运行信号和当前选择。
- 使用硬边、细线、开放留白和规则网格，不使用圆角卡片墙。
- 大标题只用于页面入口；控制区、结果区保持紧凑，适合连续操作。
- 模块之间通过层级、线条和类型色区分：Skill 为青色，Tool 为黄色，MCP 为红色。
- 状态使用小型方点与文字，不依赖巨大的状态块。
- 动效只承担状态变化和导航反馈，不加入影响操作的背景动画。

参考站点可观测的主要颜色包括纯黑、纯白、深灰，以及 `#18d1ff` 附近的青色强调；YUMENO 将其转换为同时支持浅色与深色主题的语义令牌。

## 页面边界

静态壳继续负责导航、视图缓存、音频解锁和跨页生命周期。Vue 页面通过桥接模块注册 `init`、`onShow` 和 `onHide`：

- 首次进入时挂载。
- 再次进入时刷新必要数据并恢复后台任务。
- 离开时停止页面轮询，但不终止服务端任务。
- 页面销毁时清理定时器。

后端 API、数据库结构、QQ、B站、Live2D、TTS 和对话调用链不因本轮迁移改变。

## 共享前端结构

```text
frontend/src/
  main.ts
  shared/
    api.ts
    design-tokens.css
  manage/
  extensions/
  evaluation/
```

三个 Vue 页面由同一生产包提供，Vue 运行时只打包一次。当前生产包包含管理画布依赖，适合本地桌面应用按需加载；未来页面数量增加后，再拆成共享 chunk 与页面 chunk。
