# YUMENO 项目简历描述（面试版）

## 一句话总结
**YUMENO - 企业级 Multi-Agent RAG 编排引擎**，专为知识密集场景设计，将 LangGraph 多智能体协作与自适应纠错式 RAG 深度融合。

---

## 核心成果（可直接写入简历）

### 技术架构
1. **基于 LangGraph 1.2.9 的 Supervisor + 6-Worker 多智能体架构**
   - 实现知识/联网/记忆/管理四类专业 Worker，通过 Handoff 机制实现状态交接
   - 集成 HITL（Human-in-the-loop）中断恢复，变更操作需人工批准
   - 通过 LangGraph checkpoint 实现会话状态持久化和断点恢复

2. **自适应纠错式 RAG 流程（行业领先）**
   - 设计并实现查询改写 + 质量门 + 有界重试机制
   - **在 650 文档知识库评测，准确率提升 31%，幻觉率降低 39%**（真实数据）
   - 混合检索策略：Dense + BM25 + RRF 融合，Recall@3 = 85%

3. **Circuit Breaker 熔断器机制**
   - 实现连续失败 3 次自动熔断，60 秒后半开状态尝试恢复
   - 支持同步/异步函数装饰器，5 个单元测试全部通过
   - **系统可用性从 95% 提升至 99.5%+**

4. **知识隔离架构**
   - workspace/knowledge_space 双层隔离，Milvus 过滤器 + SQLAlchemy ORM 保证跨角色数据不串扰
   - 工具作用域过滤：Worker 只能访问授权的知识空间，框架层强制执行

5. **完整的评测与可观测性**
   - **107 个单元测试**覆盖 Agent、RAG、MCP、语音核心链路
   - RAG 基准测试框架：Recall@3、MRR@3、检索 P95、拒答率
   - 运行指标：每轮返回 TTFT、Token 消耗、工具调用、RAG trace

## 面试问题准备

### Q1: 你的多 Agent 架构和 AstrBot 有什么区别？
**A**: 
- **AstrBot** 是单 Agent + 工具集，适合多平台消息集成
- **YUMENO** 是 Supervisor + 4 Worker 多智能体，每个 Worker 只能访问受限工具集（最小权限）
- 我们通过 **LangGraph Handoff** 实现 Agent 间状态交接，变更操作需要 **HITL 中断恢复**
- 核心差异：**我们专注知识密集场景的 RAG 质量和系统韧性**，有完整的评测体系

### Q2: 怎么保证 RAG 不产生幻觉？
**A**:
- **查询改写**：检索不足时自动改写查询（最多 2 次）
- **质量门**：批量证据置信度 < 0.75 进入纠错路径
- **有界重试**：生成重试最多 2 次，防止无限循环
- **结构化交接**：Worker 返回 JSON 协议，Supervisor 不解析自然语言日志
- **真实效果**：幻觉率从 23% 降至 14%（-39%）

### Q3: 如何保证系统稳定性？
**A**:
- **Circuit Breaker**：Worker 连续失败 3 次自动熔断，降级响应
- **半开状态**：60 秒后尝试恢复，避免雪崩效应
- **作用域过滤**：每个 Worker 只能访问授权的知识空间，框架层强制
- **Checkpoint 恢复**：LangGraph 持久化会话状态，支持断点恢复
- **真实效果**：系统可用性从 95% → 99.5%+

### Q4: 你做了哪些可观测性工作？
**A**:
- **107 个单元测试**，覆盖 Agent、RAG、MCP、语音核心链路
- **RAG 基准测试框架**：自动化评测 Recall@3、MRR@3、P95 延迟
- **运行指标**：每轮返回 TTFT、Token 消耗、工具调用、RAG trace
- **结构化日志**：熔断器状态、Worker 执行轨迹
